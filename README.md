# 🌍 BPhO Computational Challenge 2023 — Project Website

> **🏆 Top 5 Gold Award — British Physics Olympiad (BPhO) Computational Challenge 2023**
> Awards ceremony held at the **Royal Society**, London. Research presented at the **Tonbridge Science Conference**.

An interactive web application presenting our submission for the British Physics Olympiad Computational Challenge 2023. The site provides a detailed writeup of our solar system simulation, including the physics, methodology, results, and interactive visualisations — with mathematical typesetting powered by MathJax.

🌐 **[Visit the Live Website](http://challenges.my-innovations.co.uk)**

📄 **[Read the Research Paper](https://www.overleaf.com/read/snrcdymjktzx#feda45)**
🎮 **[Unity Solar System Simulation](https://github.com/yuyaox122/Solar-System-Unity)**

## ✨ Features

- **Interactive visualisations** — dynamic charts and diagrams of orbital mechanics and simulation results
- **Mathematical typesetting** — LaTeX-style equations rendered via MathJax for full academic presentation
- **Responsive design** — built with Tailwind CSS for clean, modern layout across all screen sizes
- **Fast build pipeline** — Vite-powered development and production builds for snappy performance
- **Research writeup** — full methodology, physics derivations, and results from our simulation

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16+)
- npm

### Installation

```bash
git clone https://github.com/yuyaox122/Computational-Challenge-2023-Website.git
cd Computational-Challenge-2023-Website
npm install
```

### Development

```bash
npm run dev
```

The site will be available at `http://localhost:5173`.

### Production Build

```bash
npm run build
```

Built files are output to the `dist/` directory.
